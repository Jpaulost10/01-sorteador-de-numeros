
# 🎲 DevSorteio

Aplicação web desenvolvida para realizar sorteios de números inteiros dentro de um intervalo definido pelo usuário.

O projeto foi desenvolvido com HTML, CSS e JavaScript, com foco na aplicação prática dos conceitos fundamentais de programação e manipulação do DOM.

## 🌐 Acesse o projeto

🚀 **[Testar o DevSorteio](https://jpaulost10.github.io/01-sorteador-de-numeros/)**

## 📸 Demonstração

![DevSorteio](./imagens/preview.jpeg)

## 🚀 Funcionalidades

- Sorteio aleatório de números inteiros.
- Definição de intervalo personalizado pelo usuário.
- Validação de campos obrigatórios.
- Verificação de valores negativos.
- Validação de números inteiros.
- Verificação da ordem dos valores informados.
- Exibição do resultado diretamente na página.
- Funcionalidade para reiniciar a aplicação.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## 💡 Aprendizados

Durante o desenvolvimento, foram aplicados conceitos como:

- Manipulação do DOM.
- Eventos com `addEventListener()`.
- Funções e variáveis.
- Conversão de tipos com `Number()`.
- Operadores lógicos.
- Estruturas condicionais (`if`).
- Métodos matemáticos (`Math.random()` e `Math.floor()`).
- Validação com `Number.isInteger()`.
- Manipulação de elementos com `textContent`, `value`, `focus()` e `hidden`.

## ▶️ Como executar

1. Clone este repositório.
2. Acesse a pasta `01-sorteador-de-numeros`.
3. Abra o arquivo `index.html` no navegador. Não é necessário instalar dependências.
4. Informe os números inicial e final.
5. Clique em **Sortear**.
